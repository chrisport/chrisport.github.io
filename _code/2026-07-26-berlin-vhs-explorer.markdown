A powerful search UI for courses of Berlin's Volkshochschulen, built on the city's open data. Built with AI.
A GitHub Action converts the data into a small SQLite database, which the page queries directly in the browser with sql.js (no backend).
Filter by district, start date, price and free seats, exclude keywords, and bookmark courses for later.
